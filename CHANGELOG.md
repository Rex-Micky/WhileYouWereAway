# Changelog

All notable changes to WhileYouWereAway are documented here.
This project adheres to [Semantic Versioning](https://semver.org/).

## [Unreleased]

Initial feature set — pending in-game testing before the first tagged release.

### Added
- Login recap: time away and in-game days passed.
- Who logged in while you were away, with new players flagged.
- "Near your base" visitor tracking while you're offline.
- Offline mail: `/wywa mail <player> <message>`, delivered instantly if online or on next login.
- `/wywa setbase` and `/wywa base` to manage your watched location.
- Configurable recap sections, base radius, thresholds and messages; persistent across restarts.
